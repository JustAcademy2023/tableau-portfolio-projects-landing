Ten dashboards, ten different lessons

Each project below is picked to teach a different piece of Tableau, from calculated fields to geographic mapping, so the set adds up to more than the sum of its parts.

01 / Retail

Retail sales performance dashboard

Track revenue, margin and order volume across regions using the Superstore dataset, then dig for the one category quietly losing money while sales look healthy on the surface.

Bar chartFiltersCalculated fields
02 / Retail Ops

Inventory management dashboard

Flag reorder points automatically with a traffic light logic instead of eyeballing stock counts.

LogicAlerts
03 / Marketing

Social media engagement dashboard

Pick one growth story, engagement by content type, and resist plotting every vanity metric available.

TrendsRatios
04 / Leadership

Executive KPI overview

Fit the company's health into five scannable numbers. No legend required to understand it.

RestraintSparklines
05 / Operations

Project management timeline with a hand built Gantt view

Tableau has no native Gantt tool, so you construct one from bar marks and date logic. The friction is where the real learning happens, and it is exactly the kind of build consulting and IT firms look for.

GanttDate mathStatus tracking
06 / People

Workforce and attrition dashboard

An HR analytics build most beginner portfolios skip entirely, which is exactly why it stands out.

CohortsRetention
07 / Finance

Budget vs. actual tracking dashboard

Make variance impossible to miss using running totals and simple, disciplined colour logic.

VarianceBullet chart
08 / Analytics

Customer segmentation, built in SQL first

Query recency, frequency and spend yourself before Tableau ever opens, then visualise the segments.

SQLRFM model
09 / Geography

Real estate market map dashboard

Most portfolios avoid maps entirely. Property price data makes geographic charts an easy, forgiving add.

MapsPrice trends
10 / E-commerce

End to end customer journey dashboard

Blend several data sources, track cart abandonment and repeat purchase rate, and let one chart filter the rest through action filters. This is the capstone build, closest to a real analyst's daily work.

BlendingAction filtersFunnel logic
